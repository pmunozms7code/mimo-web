¿Qué son GitHub y Netlify?

GitHub es como una "nube" para guardar el código de tu web de forma segura y con historial de cambios. Es gratuito y el estándar de la industria.

Netlify es el servicio que toma tu código de GitHub y lo publica en internet automáticamente. Cada vez que actualizas algo en GitHub, Netlify actualiza tu web en segundos. Todo gratis.

🔁 El flujo completo:

Tu PC → GitHub (guardar código) → Netlify (publicar en internet) → Visitan tu web

1

Parte 1 – Instalar Git en tu PC Solo una vez

Git es el programa que conecta tu PC con GitHub. Solo necesitas instalarlo una vez.

1
Descarga Git Ve a git-scm.com/download/win y descarga la versión para Windows. Ejecuta el instalador y haz clic en "Next" en todas las pantallas (no cambies nada).
2
Verifica la instalación Abre el menú Inicio → escribe cmd → Enter. En la ventana negra escribe: 
git --version

Si aparece algo como git version 2.x.x, está instalado correctamente.

3
Configura tu nombre y email (solo una vez) En la misma ventana negra, escribe estos dos comandos (cambia los datos por los tuyos): 
git config --global user.name "Noelia Mimo"
git config --global user.email "tu@email.com"
2

Parte 2 – Crear cuenta en GitHub Solo una vez

1
Regístrate en GitHub Ve a github.com → clic en "Sign up" → registra con tu email → elige el plan gratuito.
2
Crea un repositorio nuevo Una vez dentro de GitHub, haz clic en el botón verde "New" o en el icono "+" → "New repository".
3
Configura el repositorio así: • Repository name: mimo-web
• Visibilidad: Public (gratis)
• NO marques "Add a README file"
• Clic en "Create repository"
💡
Guarda la URL de tu repositorio. Será algo como: https://github.com/tu-usuario/mimo-web.git
3

Parte 3 – Subir tu proyecto a GitHub

Ahora vamos a conectar tu carpeta weblazos con GitHub desde la terminal.

1
Abre la terminal EN tu carpeta del proyecto En el Explorador de Windows, navega hasta tu carpeta weblazos. Luego en la barra de direcciones escribe cmd y presiona Enter. Se abrirá la terminal ya dentro de esa carpeta.
📂
Ruta de tu proyecto: C:\Users\pmuno\OneDrive\Escritorio\Proyectosweb\weblazos
2
Inicializa Git en la carpeta Escribe el siguiente comando y presiona Enter: 
git init
3
Agrega todos tus archivos 
git add .
4
Crea tu primer "commit" (punto de guardado) 
git commit -m "Primer subida del proyecto Mimo"
5
Conecta con tu repositorio de GitHub Reemplaza tu-usuario por tu nombre de usuario de GitHub: 
git remote add origin https://github.com/tu-usuario/mimo-web.git
git branch -M main
6
Sube los archivos a GitHub 
git push -u origin main

La primera vez te pedirá iniciar sesión con tu cuenta de GitHub. Sigue las instrucciones en pantalla (puede abrirse una ventana del navegador para autorizar).

✅ ¿Cómo saber si funcionó?

Ve a https://github.com/tu-usuario/mimo-web en el navegador. Debes ver todos tus archivos listados ahí.

4

Parte 4 – Publicar con Netlify ¡Gratis!

Con el código en GitHub, publicar en Netlify tarda menos de 5 minutos.

1
Crea cuenta en Netlify Ve a netlify.com → clic en "Sign up" → elige "Sign up with GitHub". Esto conecta Netlify con tu cuenta de GitHub directamente.
2
Agrega un nuevo sitio En el panel de Netlify, haz clic en "Add new site" → "Import an existing project".
3
Conecta con GitHub Elige "Deploy with GitHub". Netlify te pedirá permiso para acceder a tus repositorios. Acepta.
4
Selecciona tu repositorio Busca y selecciona mimo-web de la lista.
5
Configura el deploy Netlify detectará que es un proyecto HTML simple. Deja todo como está:
• Branch to deploy: main
• Build command: (vacío)
• Publish directory: / o (vacío)
Clic en "Deploy mimo-web".
6
¡Espera 30-60 segundos! Netlify desplegará tu web. Al terminar verás un link como: https://mimo-lazos.netlify.app
🎉 ¡Tu web está en internet!

Comparte ese link con quien quieras. Ya es pública y accesible desde cualquier parte del mundo.

✏️
Cambia el nombre del subdominio (opcional): En Netlify → "Site settings" → "Domain management" → "Options" → "Edit site name". Puedes poner algo como mimo-mascotas y quedará mimo-mascotas.netlify.app.
5

Parte 5 – Conectar tu dominio propio Opcional

Si compraste un dominio propio (ej: mimomascotas.com), estos son los pasos para conectarlo a Netlify:

1
En Netlify: agrega tu dominio Ve a tu sitio en Netlify → "Site settings" → "Domain management" → "Add domain" → escribe tu dominio → "Verify" → "Add domain".
2
Netlify te dará 4 "nameservers" Se verán así: dns1.p04.nsone.net, dns2.p04.nsone.net, etc.
3
En tu proveedor de dominio (Namecheap/GoDaddy): cambia los nameservers Entra al panel donde compraste el dominio → busca "Nameservers" o "DNS" → cambia los nameservers por los que te dio Netlify → guarda.
4
Espera 24-48 horas Los cambios de DNS tardan en propagarse. Netlify también activará HTTPS (certificado SSL gratuito) automáticamente.
🔒
Netlify incluye HTTPS gratis: Tu web tendrá el candado verde de seguridad (https://) automáticamente. Esto también ayuda al SEO.
6

Parte 6 – Cómo actualizar tu web en el futuro

Cada vez que hagas cambios en tu web y quieras que se vean en internet, solo tienes que ejecutar 3 comandos en la terminal de tu carpeta:

# 1. Agregar todos los cambios
git add .

# 2. Guardar con un mensaje descriptivo
git commit -m "Descripción de lo que cambiaste"

# 3. Subir a GitHub (Netlify actualiza automáticamente)
git push
⚡ Netlify detecta el push automáticamente

En menos de 60 segundos tu web estará actualizada. No tienes que hacer nada más en Netlify.

Ejemplos de mensajes de commit:

git commit -m "Agrego nueva sección de colección"
git commit -m "Corrijo texto de la sección Nosotros"
git commit -m "Actualizo número de WhatsApp"
💡
Tip: Cada commit es un punto en el tiempo al que puedes volver si algo sale mal. Por eso es importante ponerles mensajes descriptivos.
